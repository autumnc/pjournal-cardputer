# pjournal-cardputer

ESP32-S3 上的个人日记工具，运行于 **M5Stack Cardputer**。把 pjournal-esp32 移植到 Cardputer 的小屏幕（240×135），因屏幕过小移除了 GTD 模块，保留了快捷编辑等常用功能。

## 硬件

| 组件 | 规格 |
|------|------|
| **设备** | M5Stack Cardputer |
| **主控** | ESP32-S3，Flash 8MB（无需 PSRAM） |
| **屏幕** | ST7789 240×135 横屏（SPI），自定义 `u8g2_st7789` 驱动 |
| **键盘** | Cardputer 内置键盘（GPIO 矩阵扫描），支持 Fn / Shift / Ctrl |
| **SD卡** | SPI 模式，FAT32 |
| **电池** | 单节锂电池，ADC 分压检测 |
| **按键** | BOOT (GPIO0)：长按休眠、单击无动作 |

**引脚定义**: 见 `main/user_config.h`（背光 GPIO38 LEDC PWM）

## 功能特性

- **自由写作 / 提示写作**：新建日记条目（提示为随机选题）
- **快捷编辑模式**：开机直接进编辑器，SD 根目录 `0.txt`~`9.txt` 十个文件，`Fn+0-9` 切换，自动保存，重启继续上次编辑，跳过 NTP 时间同步最快开机
- **拼音输入法**：中文输入、词库联想、用户词典，`Ctrl+Space` 中/英切换，`Shift+Space` 全角/半角，`Ctrl+Shift+F` 繁/简切换，左Shift单击临时英文模式
- **过往日记浏览** (`v`)：按日期排序、查看详情、编辑、删除
- **大纲写作** (`o`)：大纲式写作，支持项目、标题层级、详情面板、导出 Markdown
- **灵感面板** (`Ctrl+I`)：快速记录灵感，关键词检索、复制到剪贴板
- **WebDAV 同步** (`w`)：上传/下载日记到远程存储
- **发送至 Flomo** (`Ctrl+F`)：即时反馈面板，防止重复发送
- **AI 提示生成** (`Ctrl+P`)：根据个人设置生成写作提示（快捷编辑模式不启用）
- **Web 文件管理**：通过浏览器管理 SD 卡文件（设置 → 文件管理）
- **USB 存储模式**：按住 `E` 开机进入，SD 卡以 U 盘形式挂载到电脑
- **编辑器**：Markdown 实时渲染、自动保存、选择/复制/粘贴
- **显示**：暗色/亮色模式、背光调节（`Ctrl+=` / `Ctrl+-`）
- **自动休眠**：10 分钟无操作进入 light sleep，BOOT 键唤醒

## Markdown 渲染

编辑器支持 Markdown 实时语法渲染（可在设置中关闭）。所有标记均替换为同宽内容，光标、选中、折行保持对齐。

### 块级标记

| 输入 | 渲染效果 |
|------|----------|
| `#` ~ `######` 标题 | 行首标记替换为标题符号，内容加粗 + 下划线 |
| `- ` / `* ` / `+ ` 无序列表 | `• ` 圆点 |
| `1. ` / `1)` / `1、` 有序列表 | 序号加粗，整体右移 1 格 |
| `一、` / `二、` / `十、` 中文序号 | 中文序号加顿号加粗，整体右移 1 格 |
| `- [ ]` / `- [x]` 任务 | `☐` / `✓` |
| `> ` 引用 | 左侧竖线 + 内容缩进 |
| `---` / `***` / `___`（≥3 个） | 水平分割线 |
| ```` ``` ```` 代码围栏 | 围栏行画横线，围栏内内容反白 |

### 行内标记

| 输入 | 渲染效果 |
|------|----------|
| `**加粗**` / `***加粗+下划线***` | 加粗 / 加粗 + 下划线 |
| `*斜体*` | 下划线 |
| `` `代码` `` | 反白 |
| `[链接](https://…)` | 反白 + 下划线 |
| `~~删除~~` | 删除线 |
| `==高亮==` | 着重号 |
| `\*` | 转义，显示原文 |

列表行在行尾回车自动续行：下一行带同款标记；有序列表序号自动递增（`1.`→`2.`、`一、`→`二、`）。空列表项回车结束列表。

## 编译

### 环境要求

- ESP-IDF **5.5**
- 目标芯片: ESP32-S3（M5Stack Cardputer）

### 编译步骤

```bash
# 加载 ESP-IDF 环境
. /path/to/esp-idf/export.sh

# 编译
idf.py build

# 生成合并固件（bootloader + partition + app）
python -m esptool --chip esp32s3 merge_bin -o build/merged.bin \
  --flash_mode dio --flash_size 8MB --flash_freq 80m \
  0x0 build/bootloader/bootloader.bin \
  0x8000 build/partition_table/partition-table.bin \
  0x10000 build/pjournal.bin
```

### 烧录

```bash
# 合并固件一步烧录（配合 USB 转串口模块）
python -m esptool --chip esp32s3 -p /dev/ttyUSB0 -b 460800 \
  --before default_reset --after hard_reset \
  write_flash 0x0 build/merged.bin

# 或直接通过 USB 口
idf.py -p /dev/ttyUSB0 flash
```

## SD 卡目录结构

```
/sdcard/
├── pjournal/          # 日记文件 (YYYY-MM-DD_HHMMSS.txt) 与灵感数据
├── settings/          # 设置（每个键一个文件）
├── outline/           # 大纲写作
│   ├── *.json         # 大纲项目
│   └── inspiration.json  # 灵感数据
├── 0.txt ~ 9.txt      # 快捷编辑文件（SD 根目录）
└── (文件管理/WebDAV 等按需生成)
```

## 设置项

| 设置 | 说明 |
|------|------|
| 文件管理 | 浏览器访问 SD 卡文件 |
| Deepseek Key | AI 提示生成 API Key |
| Flomo 邮箱/密码 | Flomo API 登录凭证 |
| 生成 Flomo Token | 由邮箱/密码生成 API Token |
| WebDAV URL/用户/密码 | 远程同步地址 |
| 个人经历/爱好 | AI 提示上下文 |
| WiFi SSID/密码 | 网络连接 |
| 时区 | 如 `CST-8` |
| NTP 服务器 | 如 `pool.ntp.org` |
| 自动保存 | 开启后 3 秒无操作自动存储 |
| 自动休眠 | 开启后 10 分钟无操作进入 light sleep |
| 休眠保留画面 | 开启后休眠期间保留最后画面；关闭则白屏最省电 |
| Markdown渲染 | 编辑器 Markdown 实时渲染开关 |
| 显示模式 | 暗色（黑底白字）/ 亮色（白底黑字） |
| 编辑模式 | 个人日记 / 快捷编辑（重启生效） |
| 网络同步时间 | 联网后同步 RTC 时间 |

> 提示：快捷编辑模式下 `Esc` 跳到设置面板，再按 `Esc` 返回编辑器。

## 与 pjournal-esp32 的差异

- 屏幕：RLCD 400×300 → **ST7789 240×135**
- 键盘：蓝牙 HID → **Cardputer 内置键盘**
- 移除：GTD 任务管理、蓝牙管理、语音输入、字体缩放
- 新增：快捷编辑模式、USB 存储模式
